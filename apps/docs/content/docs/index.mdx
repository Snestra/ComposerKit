---
title: Render your first Composer
description: "Add one ComposerKit message box to a new Next.js app."
---

A page with one Composer, a message box you can type into. Sending shows the text below the box. No AI service or API key is needed.

Use Node.js 26 and npm, in an empty folder named `composerkit-demo`. ComposerKit installs through the shadcn registry, which copies the component source into your app.

## 1. Create the app

```bash
npx --yes create-next-app@latest . --yes --use-npm --disable-git --src-dir
```

## 2. Add the ComposerKit registry

The first command sets up shadcn in the app. The second command tells shadcn where the `@composerkit` components live.

```bash
npx shadcn@latest init --defaults --yes
npx shadcn registry add '@composerkit=https://bjoernaagaard.github.io/ComposerKit/r/{name}.json'
```

## 3. Add the Composer

The command copies the Composer, the components it uses and the ComposerKit styles into `src`. It replaces the `src/lib/utils.ts` file that shadcn created with the ComposerKit version.

```bash
npx shadcn add @composerkit/composer --overwrite --yes
```

Replace the global styles with the ComposerKit styles, which include Tailwind CSS.

```css title="src/app/globals.css"
@import "../styles/globals.css";
```

## 4. Render the Composer

Replace `src/app/page.tsx` with the file below. Keep `"use client"` at the top, because the page keeps the draft in React state in the browser.

```tsx title="src/app/page.tsx"
"use client";

import { InlineComposer } from "@/components/ui/composer";
import { TooltipProvider } from "@/components/ui/tooltip";
import { useState } from "react";

export default function Home() {
	const [draft, setDraft] = useState("");
	const [sentText, setSentText] = useState("");

	return (
		<main className="bg-background text-foreground min-h-dvh p-8">
			<div className="mx-auto max-w-2xl">
				<TooltipProvider>
					<InlineComposer
						canCancel={false}
						canSubmit={draft.trim() !== ""}
						label="Write a message"
						multiline
						onCancel={() => {}}
						onSubmit={() => {
							setSentText(draft);
							setDraft("");
						}}
						submitLabel="Send"
					>
						<textarea
							aria-label="Write a message"
							className="w-full resize-none bg-transparent outline-none"
							onChange={(event) => setDraft(event.target.value)}
							placeholder="Write a message"
							rows={1}
							value={draft}
						/>
					</InlineComposer>
				</TooltipProvider>
				<p aria-live="polite" className="mt-4">
					{sentText}
				</p>
			</div>
		</main>
	);
}
```

## 5. See the message box

```bash server="http://localhost:3060"
npm run dev -- --port 3060
```

Open `http://localhost:3060`. Type a message and press Enter. Your text appears below the box.

## 6. Build the app

Stop the server with Ctrl+C, then build for production.

```bash
npx next build
```

Next.js lists `/` as a static route and exits without an error.

Continue with the [Composer component](/docs/components/composer).
