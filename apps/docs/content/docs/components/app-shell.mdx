The sidebar and the conversation are slots. Content tabs and their callbacks come through props. Drag a tab to a side quarter to move the tab pane there.

<ComponentDoc name="app-shell" />

## Keyboard

```text
Ctrl+Tab / Ctrl+Shift+Tab        next / previous tab
Ctrl+1 … Ctrl+9                  select tab by position
Ctrl+T / Ctrl+W                  new tab / close active tab
Ctrl+Shift+B                     hide or show the tab pane
ArrowLeft, ArrowRight, Home, End move between tabs
Delete                           close the focused tab
Shift+F10 / Menu key / right-click  open the tab menu
```
